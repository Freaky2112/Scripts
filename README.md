# **Scripts**

![Bash](https://img.shields.io/badge/Bash-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white&color=293137) ![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

Welcome to the **ultimate scripts playground**! 🚀
A small collection of Bash, Python, Windows, and experimental scripts — all in one repo for your tinkering pleasure.

---

## 🧩 What’s Inside?

This repo is basically a **toolbox**:

- 🐚 **Bash** — shell goodies for automation and daily hacks
- 🐍 **Python/Scanner** — small utilities and experiments
- 🗑️ **Temp_cleanup** — clean your junk, save your soul
- 🧪 **Test Scripts** — experiments and prototypes
- 💻 **Windows** — batch scripts and Windows utilities

> Pro tip: everything is standalone. Pick what you like, tweak it, run it. No magic required.

---

## ⚡ Quick Start

Clone it, explore it, run it:

```bash
git clone https://github.com/Freaky2112/Scripts.git
cd Scripts
git checkout
```

Run scripts like a boss:

```bash
# Bash example
chmod +x myscript.sh
./myscript.sh

# Python example
python3 Scanner/myscript.py
```
