# Scripts

A collection of various scripts — Bash, Python, utilities, cleanup tools, and more — organized for different tasks and platforms.  

## 🧰 What is this repository for?

This repository collects “all-kinds-of-scripts” that I use or develop, including but not limited to:  
- Bash / shell scripts  
- Python utilities (e.g. `Scanner`)  
- Windows batch / Batchfile scripts  
- Test / prototype scripts  

It’s basically a toolbox: a set of standalone (or loosely related) scripts to help with automation, maintenance tasks, or quick utilities.
